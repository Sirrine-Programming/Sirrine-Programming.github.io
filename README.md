# Sirrine Programming Portfolio (`sirrine-programming.github.io`)

Official portfolio and catalog showcase for **Sirrine Programming** VR games, mixed reality experiences, and spatial computing applications built natively for Meta Quest.

Live site: [https://sirrine-programming.github.io](https://sirrine-programming.github.io)

## Featured Meta Quest Titles

- **[Skybound Quest](https://www.meta.com/experiences/skybound-quest/1120517883894304/)** — First-principles alpine paragliding flight simulator for Meta Quest 3/3S/Pro/2.
- **[Icosa Skies (Nova)](https://www.meta.com/experiences/icosa-skies/1122518520360907/)** — Low-poly planetary 6DOF arcade dogfighter with seamless space-to-atmosphere flight.
- **[Skoven](https://www.meta.com/experiences/skoven/)** — Voice-driven AI agent spatial workspace for Meta Quest.
- **[Cielos](https://www.meta.com/experiences/cielos/)** — High-altitude spacecraft dogfighting (also live at [cielosvr.space](https://cielosvr.space)).
- **[Dead Zone: Wave Breaker](https://www.meta.com/experiences/dead-zone/)** — Room-scale mixed reality horde defense using Meta Quest 3 passthrough.
- **[Archivist](https://www.meta.com/experiences/archivist/)** — Generative voice-first 3D world builder for Meta Quest.
